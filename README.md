# CDISC Pilot Study: Survival Analysis

## 📌 Project Overview
This repository contains an R Markdown report analyzing clinical trial data from the CDISC Pilot Study. The analysis evaluates the Time to Deterioration Event (TTDE) across three treatment arms (Placebo, Xanomeline High Dose, and Xanomeline Low Dose).

## 🛠️ Skills Demonstrated
*   **Data Wrangling:** Cleaning clinical data, handling missing values, and merging ADaM datasets (`ADSL` and `ADTTE`) using `dplyr`.
*   **Survival Analysis:** Non-parametric estimation using Kaplan-Meier plots (with risk tables and confidence intervals) and semi-parametric modeling using Cox Proportional Hazards.
*   **Reporting:** Reproducible research using R Markdown to combine code, visualizations, and clinical interpretation.
